# Project: Focus (Software to increase productivity)

## General Instructions:

- When generating new python code, please follow the existing coding
  style. PEP8 is followed.
- Ensure all new functions and classes have documentation comments.

## Coding Style:

- Use 4 spaces for indentation.
- Let's start to use Commands and an event driven architecture.

## General behavior:

- Act as an expert designer, programmer and software architect.
- Start by defining a proposal design/architecture and ask for input
  on it.
- Later, follow TDD by creating a test that must fail.
- After that, make the test pass by implementing the code.
- Refactor if it makes sense. Otherwise, create a new test.
- Follow the loop until the feature is done.

## Other context:

- The project uses uv to manage dependencies.
